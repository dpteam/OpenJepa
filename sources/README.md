# Источники

Здесь лежат первичные материалы, с которых начался проект.

## Что есть

| Файл | Что это |
|---|---|
| `55d0Fti7dwk.ru.vtt` | авто-субтитры YouTube (русский, исходный формат WebVTT) |
| `55d0Fti7dwk.ru-orig.vtt` | копия оригинала от yt-dlp |
| `55d0Fti7dwk.ru.txt` | очищенный транскрипт: сплошной текст + блоки с таймкодами |
| `video-55d0Fti7dwk.md` | конспект с разбором: что подтверждается, а что преувеличено |

## Как получены

```bash
yt-dlp --skip-download --write-auto-subs --write-subs \
       --sub-langs "ru.*,en.*" --sub-format "vtt" \
       -o "sources/%(id)s.%(ext)s" \
       "https://www.youtube.com/watch?v=55d0Fti7dwk"

python tools/vtt2txt.py sources/55d0Fti7dwk.ru.vtt sources/55d0Fti7dwk.ru.txt
```

Скрипт `tools/vtt2txt.py` убирает «накатывающиеся» повторы авто-субтитров
(каждая строка частично повторяет предыдущую) и собирает текст в блоки
примерно по 45 секунд.

## Ограничения

* Авто-субтитры содержат ошибки распознавания: «Ян Ликун» вместо
  «Ян ЛеКун», «АмилепS»/«АЛЭbs»/«AMABS» вместо «AMI Labs», «Джепа» вместо
  «JEPA». В конспекте исправлено, в `.vtt` — как есть.
* Последние ~1.5 минуты видео — не по теме (нарезка мемов), в транскрипте
  оставлены, но в конспект не включены.
* Числа из видео **не** являются первоисточником. Все проверяемые
  утверждения сверены с arXiv-препринтами, см. `research/bibliography.md`.
