# OpenJEPA

Архитектура, теория и рабочая реализация ИИ на основе **JEPA** (Joint-Embedding
Predictive Architecture) — подхода Янна ЛеКуна к моделям мира.

Репозиторий отвечает на три вопроса:

1. **Почему** предсказание следующего токена — не путь к пониманию мира.
2. **Как** устроена система, которая учится предсказывать в латентном
   пространстве, планирует в нём и помнит.
3. **Что уже работает** — код обучения, планировщик и рантайм, которые
   запускаются на одной GPU за минуты.

---

## Быстрый старт

```bash
python -m pip install -e .          # или: pip install -r requirements.txt
export PYTHONPATH=src               # Windows: $env:PYTHONPATH="src"

python tests/run_all.py                              # 29 тестов, ~40 секунд
python -m openjepa.runtime.cli train --config configs/pretrain_toy.yaml
python -m openjepa.runtime.cli eval  --ckpt runs/toy/best.pt --episodes 20
python -m openjepa.runtime.cli demo  --ckpt runs/toy/best.pt --out runs/demo.png
```

Что происходит: модель учится предсказывать эмбеддинг следующего кадра
движущегося мяча, а затем CEM-планировщик в латентном пространстве ведёт мяч
к цели. Без пиксельного декодера, без reward-модели, без обучения с подкреплением.

## Главная мысль

JEPA — это не «ещё одна архитектура нейросети». Это смена целевой функции:

```
было:  предскажи следующий токен
стало: предскажи эмбеддинг будущего наблюдения и научись планировать в нём
```

Всё остальное — энкодер, предиктор, регуляризация, иерархия, планировщик —
следует из этого выбора.

Подробнее: `docs/02-chto-takoe-jepa.md`.
